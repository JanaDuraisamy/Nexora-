## Conventions

- One decision per file, numbered sequentially.
- Status is one of `PROPOSED`, `ACCEPTED`, `REJECTED`, `SUPERSEDED`.
- Approval is recorded separately from proposal text; approved decisions are not
  silently edited into history.
- Implementation deviations require a new ADR or an explicit amendment section,
  not a rewrite of the original.
